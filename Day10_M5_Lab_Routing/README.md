# 🧪 Session 2 — Power Distribution

## Lab 1 — Build Power Distribution

**Objective:** Practice the prescribed workflow for building the power distribution network of the physical design.

**Activities**

- Prepare the design for power distribution.
- Follow the provided power-network implementation steps.
- Establish the required power and ground connections.
- Review the resulting power-distribution structure.

**Learning outcome**

Gained practical exposure to implementing a power distribution network within the physical design flow.
