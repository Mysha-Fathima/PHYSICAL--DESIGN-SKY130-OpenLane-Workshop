## 📌 Overview

The first day of the VSD OpenLane SKY130 Physical Design Workshop introduced the fundamentals of System-on-Chip (SoC) design, RISC-V architecture, the RTL-to-GDSII flow and the open-source VLSI ecosystem.

These lecture sessions established the theoretical foundation required to understand the physical implementation of digital integrated circuits.

---

# 📖 Session 1 — How to Talk to a Chip

## 1. Introduction to QFN-48

An introduction to the QFN-48 package and its role in connecting an integrated circuit to an external printed circuit board. This topic provides an initial understanding of chip packaging and physical connectivity.

**Key concepts**

* Integrated circuit packaging
* Pin configuration and external connections
* Relationship between a chip and its surrounding system



## 2. Introduction to RISC-V

An overview of the RISC-V instruction set architecture and its role in processor design. The session introduced the fundamentals of processor architecture and how instructions are used to perform computational operations.

**Key concepts**

* RISC architecture
* Instruction set architecture (ISA)
* Processor fundamentals



## 3. From Software Applications to Hardware

An introduction to how software-level requirements are translated into hardware operations, helping establish the connection between applications, processor architecture and digital circuit implementation.

**Key concepts**

* Software and hardware interaction
* Basic computation and instruction execution
* Hardware implementation concepts



---

# 📖 Session 2 — SoC Design and Open-Source Physical Design

## 1. Introduction to SoC Design

Understanding the basic architecture of a System-on-Chip and how different functional blocks are integrated into a single chip to perform a complete system's operations.

**Key concepts**

* SoC architecture
* Functional blocks and interconnections
* Hardware integration



## 2. Simplified RTL-to-GDSII Flow

An overview of the transformation of a digital design from RTL description into a physical layout ready for fabrication.

**Key stages**

* RTL design
* Logic synthesis
* Floorplanning
* Placement
* Clock Tree Synthesis (CTS)
* Routing
* Physical verification
* GDSII generation



## 3. Introduction to Open-Source Physical Design

An introduction to the open-source physical design ecosystem and the role of accessible tools and process design kits in digital chip implementation.

**Key concepts**

* Open-source VLSI tools
* Physical design automation
* SKY130 technology
* Open-source design methodology



## 4. Introduction to OpenLane

An introduction to OpenLane as an automated RTL-to-GDSII implementation flow, including its purpose in connecting digital design with physical implementation.

**Key concepts**

* OpenLane flow
* Design implementation
* Tool integration
* Physical design stages


---

## 🧠 Key Learning Outcomes

* Understood the basic concepts of QFN-48 packaging and RISC-V architecture.
* Explored the connection between software applications and hardware.
* Learned the fundamentals of SoC design.
* Gained a conceptual understanding of the RTL-to-GDSII flow.
* Explored open-source physical design and the OpenLane ecosystem.
