## 📌 Overview

The first day of the VSD OpenLane SKY130 Physical Design Workshop introduced the fundamentals of System-on-Chip (SoC) design, RISC-V architecture, the RTL-to-GDSII flow and the open-source VLSI ecosystem.

These lecture sessions established the theoretical foundation required to understand the physical implementation of digital integrated circuits.

---

# 📖 Session 1 — How to Talk to a Chip

## 1. Introduction to QFN-48

An introduction to the QFN-48 package and its role in connecting an integrated circuit to an external printed circuit board. This topic provides an initial understanding of chip packaging and physical connectivity.

**Key concepts**

* Integrated circuit packaging
* Pin configuration and external connections
* Relationship between a chip and its surrounding system

# 📖 Session 2 — SoC Design and Open-Source Physical Design

## 1. Introduction to SoC Design

Understanding the basic architecture of a System-on-Chip and how different functional blocks are integrated into a single chip to perform a complete system's operations.

**Key concepts**

* SoC architecture
* Functional blocks and interconnections
* Hardware integration

## 2. Simplified RTL-to-GDSII Flow

An overview of the transformation of a digital design from RTL description into a physical layout ready for fabrication.

**Key stages**

* RTL design
* Logic synthesis
* Floorplanning
* Placement
* Clock Tree Synthesis (CTS)
* Routing
* Physical verification
* GDSII generation
