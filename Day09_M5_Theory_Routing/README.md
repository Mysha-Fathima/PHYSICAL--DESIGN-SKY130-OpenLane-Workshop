## 📌 Overview

Day 5 of the VSD OpenLane SKY130 Physical Design Workshop covers the final stages of the physical design flow, with emphasis on routing, design-rule verification, power distribution and TritonRoute.

The sessions introduce routing algorithms, routing verification and the role of routing tools in completing the physical implementation flow.

---

# 📖 Session 1 — Routing and Design Rules

## 1. Introduction to Maze Routing

An introduction to maze-based routing techniques used to determine valid paths between interconnected points in a physical layout.

**Key concepts**

- Routing problem
- Routing paths
- Obstacles
- Connectivity
- Routing resources
- Path optimization

## 2. Lee's Algorithm Concepts

Introduction to Lee's algorithm as a systematic approach for finding routing paths through a grid-based representation of the layout.

**Key concepts**

- Grid-based routing
- Source and destination

- Path search
- Obstacle avoidance
- Route reconstruction
